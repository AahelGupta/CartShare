# 🤝 Contributing to CartShare

Thank you for considering contributing! We welcome bug reports, feature requests, and pull requests to make CartShare even better.

## 🚀 How to Contribute

1. **Fork the Repository**: Create your own copy of the repository on GitHub.
2. **Clone Locally**:
   ```bash
   git clone https://github.com/AahelGupta/CartShare.git
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. **Commit Changes**:
   ```bash
   git commit -m "feat: add amazing feature"
   ```
5. **Push and Open a Pull Request**: Submit your PR for review!

## 📜 Code Style Guidelines
- Use clean, modular ES6+ JavaScript.
- Maintain responsive Bootstrap 5.3 UI standards.
- Keep `@media print` styling audit-ready and verified.
